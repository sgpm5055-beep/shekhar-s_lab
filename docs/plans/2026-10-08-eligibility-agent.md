## Canonical Seam Contract (binding; resolves every audit finding)

Numbered rulings. Where a dossier file says otherwise, **this section wins**.

**C1. Checks-row lifecycle.** The admission node inserts `CheckRow(status='running', billed=False, counted_against_cap=False, is_refresh=(admission=='refresh'), consent_id, created_at=now)` for EVERY admission outcome, refusals included, **before any SurePass call** (surepass_calls FK needs it). `persist` / `persist_refusal` finish with ONE `update_check` patch (status + refusal_code + billed + counted_against_cap + lc_view + internal + langsmith_run_id — satisfies the `refusal_code_iff_refused` CHECK). No `save_check`, no 'pending'/'started' status. Status domain: `running | ok | pan_invalid | refused | error` (LcView wire enum stays `ok|pan_invalid|refused`). **Terminal writes are guarded:** `update_check` to a terminal status and `record_check_error` only apply when current status is `'running'` (SupabaseRepo adds `.eq("status","running")`; MemoryRepo mirrors) — a timed-out run's late thread can never overwrite an `error` row, and vice versa.

**C2. Cache contract.** Pull nodes write `derived = {"schema_version": policy.guards.DERIVED_SCHEMA_VERSION (=1), "identity": Identity.model_dump(mode="json"), "score"|"report": ....model_dump(mode="json")}` and `payload = {"pan_comprehensive": <raw envelope>, "experian_score"|"experian_report": <raw envelope>}`. `policy.is_cache_fresh` requires `expires_at > now` AND `derived["schema_version"] == 1`. A unit test round-trips a pull-node-shaped CacheRow through `is_cache_fresh` (this was audit blocker #1 — without it, zero cache hits ever). `expires_at = fetched_at + CACHE_TTL` via `policy.cache_expiry`. LcView is never cached; gate/affordability/rank/finalize re-run per request (cache hits DO call the LLM — pinned by test 2). PAN-invalid results are not cached. No cross-kind reuse: full-after-quick re-calls PAN (test asserts exactly `[PAN_ENDPOINT, REPORT_ENDPOINT]`).

**C3. PAN hashing.** ONE function in `config.py`: `hash_pan(pan: str, *, salt: str) -> str` = `sha256(f"{salt}:{pan.strip().upper()}".encode()).hexdigest()`. Env: `PAN_HASH_SALT`. policy/db/evals import it; no second definition anywhere. Called in the route right after validation; raw PAN lives only in request scope + `CheckState.pan` (for SurePass bodies).

**C4. Repo protocol (db/repo.py is the single registry).** Rows: `ConsentRow, CacheRow, CheckRow (16 fields), CheckPatch (TypedDict total=False), SurePassCallRow, LenderRow` as frozen dataclasses (policy-design shapes). Protocol methods (exact set):
`insert_consent(row: ConsentRow) -> None` · `insert_check(row: CheckRow) -> None` · `update_check(check_id: str, patch: CheckPatch) -> None` (terminal-guard per C1) · `get_check(check_id) -> CheckRow | None` · `latest_full_check_for_opportunity(opportunity_id) -> CheckRow | None` (kind='full' AND status='ok', newest) · `quick_checks_used_today(lc_id) -> int` · `get_cache(pan_hash, kind) -> CacheRow | None` · `put_cache(row: CacheRow) -> None` (upsert on (pan_hash,kind)) · `insert_surepass_call(*, check_id, endpoint, surepass_client_id, http_status, success, message_code) -> None` (THE CallLogSink; repo stamps `called_at` from its clock/DB default) · `surepass_calls_for_check(check_id) -> list[SurePassCallRow]` · `lenders_for_pincodes(pincodes: Collection[str]) -> list[LenderRow]` (active, ≥1 match, matched_pincodes aggregated, ordered by id, `[]` on empty input without querying) · `record_check_error(*, check_id, kind, lc_id, lead_id, opportunity_id, pan_hash, message) -> None` (update-if-running else insert status='error').
MemoryRepo extras (NOT in Protocol): `seed_lender(...)`, `list_checks()`, `list_surepass_calls(check_id=None)`. `MemoryRepo(clock: Callable[[], datetime] = utc_now)`. `Clock = Callable[[], datetime]` alias lives here. db/repo.py imports only stdlib + the Literal aliases from `graph.state` (state is a pure leaf, so this stays acyclic: state ← db ← tools? no — tools imports state directly; policy imports db + tools constants; output imports state; graph imports all; main on top).

**C5. SurePass client (tools/surepass.py canonical, as designed).** Protocol `SurePassClient`: `calls_enabled: bool` property; `pan_comprehensive(check_id, pan)`; `experian_score(check_id, *, name, mobile, pan)`; `experian_report(check_id, *, name, mobile, pan)` → `SurePassResult(endpoint, http_status, success: bool, envelope_status_code, message, message_code, data, raw)` + `.client_id`. Exceptions: `SurePassError` base; `LiveCallsDisabled, SurePassAuthError, SurePassRateLimited, SurePassUpstreamError, SurePassTransportError, SurePassProtocolError, SurePassValidationError(errors, message)`. `parse_surepass_body` handles both envelope shapes (`{errors,message}` with no `success` key → raises ValidationError); `interpret_response` taxonomy: 401/403→Auth, 429→RateLimited, ≥500→Upstream, then parse, then `message_code in NON_BUREAU_FAILURE_CODES (frozenset(), ships empty)`→Upstream (prevents 30-day NTC mis-cache of infra failures), else return result (success:false envelopes RETURN typed — PAN-invalid and no-hit stay data, not exceptions). **The client owns audit logging** through the sink (= Repo.insert_surepass_call): exactly one row per HTTP attempt (http_status=None on transport failure), zero rows for LiveCallsDisabled/empty-token (no I/O happened). Graph nodes do NOT log calls. Zero retries (timed-out spend is unknown). Endpoint constants `PAN_ENDPOINT / SCORE_ENDPOINT / REPORT_ENDPOINT` live HERE; policy imports them. `LiveSurePassClient(*, token, live, sink, base_url="https://kyc-api.surepass.app", http: httpx.Client | None)`; timeouts 5s connect / 60s read. **FakeSurePassClient (merged constructor):** each endpoint arg accepts `Scenario | Mapping[pan, Scenario]` where `Scenario = SurePassResult | SurePassError | dict | tuple[int, dict]`; dict/tuple resolve through the SAME `interpret_response` path; records `FakeCall(endpoint, check_id, pan, body)` in `.calls` (+`endpoints_called()`); logs to the sink like live; `AssertionError` on unconfigured endpoint, `KeyError(pan)` on unmapped PAN; `calls_enabled=False` → LiveCallsDisabled with nothing recorded.
